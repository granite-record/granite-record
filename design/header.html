Header and navigation

Four specimens. The rule underneath all of them: one accent, used only for links, the primary button and the current-item marker; one place for the brand, always left; and chrome that belongs to a list view does not follow you onto a detail view.

Masthead, every page

Current page is an underline, not a box. The theme control has no border, so nothing outranks the nav. Data is promoted out of the footer. Brand sits on the same left rail as everything below it.
