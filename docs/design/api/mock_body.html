The Data API

The whole record behind this site, as files a program can read: every bill of every term with its full history, every roll call and every member’s vote, and one list joining every number the General Court uses for a person. No key, no account and no limit to ask about: they are plain files, rebuilt every night.

A beta until February 1, 2027. Until then a file or a field may still change, and every change is listed below. From then on, changes only add things.

The Files

Everything is under /data/, beside the spreadsheets on the data page, and data/manifest.json lists every file with its address, size and the night it was built. Start there: one request says what is here and how much. The large files are compressed with gzip, which every language and every operating system can open.

Getting Started

Every bill of the current term, in Python, with nothing to install:

import gzip, json, urllib.request
url = "https://graniterecord.org/data/bills-2025-2026.jsonl.gz"
with urllib.request.urlopen(url) as r:
    for line in gzip.decompress(r.read()).splitlines():
        bill = json.loads(line)
        print(bill["key"], bill["title"])

Or the whole database, opened in the sqlite3 program:

curl -O https://graniterecord.org/data/granite-record.sqlite.gz
gunzip granite-record.sqlite.gz
sqlite3 granite-record.sqlite "SELECT term, COUNT(*) FROM bills GROUP BY term"

A page on another site may read every file here from the reader’s browser too: each one is served to any origin.

Keys and Joins

A bill is its term and its number. HB 100 names a different bill in every term, so every file writes a bill as 2025-2026/HB1442, or as a term and a bill column side by side.

A person is a person. Employee numbers, person ids and this site’s member ids all appear in the General Court’s record, and one person can carry several of each. people.json joins them to one person, which does not change when a member moves from the House to the Senate.

When two people turn out to be one

If the record later shows that two entries are one person, the entry that goes keeps its person in a replaced_by line, so a program that stored the old one can still find them.

A blank field is usually an answer

The record leaves it empty, the document that would fill it has not been collected, or this site does not read it yet. The data page’s coverage table counts how far each column reaches in each term.

What Changed Tonight

/changes/<date>.json is what each night’s build found new, kept for the last eight nights. It already lists the hearings, votes and actions each bill, member, committee and topic gained. It now also lists every bill and person whose record changed in any way, and every file here that changed, with its checksum, so another site can fetch only what moved.

Today’s Votes

On a day the House or the Senate sits, /api/live/votes/<date> holds the roll calls recorded so far that day, refreshed during the day. It is small and changes often; the nightly files above take the day in the next morning.

What is live on the General Court’s streams is not part of the API: it comes from YouTube, whose terms do not allow passing its data on as a service. Each bill’s page still links its recording.

Versions and Stability

Every JSON file carries "format": 1. Until February 1, 2027 the API is a beta, and a field may be renamed or removed; each such change is listed here and in manifest.json a week before it happens. From February 1, changes only add: a new file, a new field, a new column at the end. A change that cannot be made by adding becomes a new file beside the old one, and both are published for at least a year.

Using It

The record is the State of New Hampshire’s and is public. What this site adds — its ids, its joins, its corrections and its timings — is dedicated to the public domain: use it for anything, with no need to ask. The code that builds it is MIT licensed. A link back to graniterecord.org helps somebody check your working.

Found something that looks wrong, or a shape that is awkward to use? Each bill’s page has a Report a problem button, and so does a note to contact@graniterecord.org.
